# Security triage — all 202 security-relevant open PRs

Every open PR whose title or description touches a vulnerability class, a CVE/GHSA, or the hardening of an untrusted-input path. Ratings are mine, from reading the PR and, where noted, the diff and the pinned dependency on `main`. CVSS is CVSS 3.1, calculated for the realistic attack path, not for the worst case.

**Read `02-security-severity.md` first** — it explains the top findings properly. This file is the complete index.

### Rating scale

| Rating | Meaning |
|---|---|
| **Critical** | Remote, unauthenticated, memory corruption in a default-on path. Patch now. |
| **High** | Remote exploitation with real impact (RCE, XSS in a privileged app, DoS of a whole server, supply-chain code execution) but a narrower path. |
| **Medium** | Local, conditional, or limited-impact exploitation — or a security control that fails open. |
| **Low** | Theoretical, developer-controlled input, latent bug with no known trigger, or defence in depth. |
| **None** | Looked security-relevant; is not. Included so the list is complete and honest. |
